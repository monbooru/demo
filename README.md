# monbooru demo

A read-only static snapshot of [monbooru](https://github.com/monbooru/monbooru) on a
sample gallery, published at <https://monbooru.github.io/demo/>. Browsing and searches work, but many features are disabled.

monbooru's code is under the AGPL-3.0, in its own repository. The artwork belongs to the artists credited and linked on each image.
