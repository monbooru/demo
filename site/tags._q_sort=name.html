Rename

Without it, saved searches naming the old spelling match nothing.

Their images get the target tag instead, and their implications move with them. The old names keep working as aliases. This cannot be undone.

The target is created if it does not exist.

Which tag do the others merge into?

    The other tags' images get the chosen tag, and their names keep working as aliases. This cannot be undone.

    Some of these tags are marked distinct; merging drops the mark.

    Every image with these tags also gets the implied tags. Add applies them to images already tagged; Remove takes back what they added.

    A tag whose cleaned name already exists merges into it. Every old name stays as an alias, so a source still sending it lands on the cleaned tag.

    Create tags. Separate names with spaces; a name may start with its category.

    An alias is another name for a tag. The target is created if it does not exist.

    Tags are removed from every image they touch. This cannot be undone. Built-in ratings are only removed from images.

    Aliases and implications the Public Tag Repository declares are added to the catalog.
